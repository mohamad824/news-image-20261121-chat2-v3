One 1024×1024 image that sums up Saturday 21 November 2026 in 35 stories: a dark night-edition front page with a cream masthead, gold stat strip, a segmented region bar, three illustrated leads, ten picture tiles, twenty-two ruled briefs, and a dot-grid world map built from Natural Earth coastlines with numbered pins marking where each story happened. Every story on the page happened or was first reported on 20–21 November 2026; the items that did not make the date are named in the red DATE CHECK box instead of being printed as news.

## Run it

```
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The program copies the rendered image to `$MAKEFUN_OUTPUT_DIR/entry.png`, deterministically, with no network access.
